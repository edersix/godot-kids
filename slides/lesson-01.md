# Lesson 1: Meet Godot

Make Your First Game in Godot

---

# Today's Goal

> "Today I will open Godot, change a message, and run my first program."

---

# What Is a Game Made Of?

Everything in Godot is made of **nodes**.

A node is a building block with **one job**.

Nodes live together in a **scene**.

---

# New Words

- **Node**: a building block with one job
- **Scene**: a group of nodes that work together
- **Inspector**: where we change a node's settings
- **Run**: start the game to see what we made

---

# The Game We Will Make

Coin Quest: a hero collects coins and avoids enemies.

*(Facilitator: show the finished game.)*

---

# Let's Build! (Part 1)

1. Open Godot and open the lesson project
2. Find these parts of the editor:
   - **Scene** panel (top left)
   - **FileSystem** (bottom left)
   - **Inspector** (right)
3. Press **Run** (or **F5**)

---

# Checkpoint

Hands up when your game window has opened and closed.

---

# Let's Build! (Part 2)

1. Click the **Message** node
2. In the **Inspector**, change **Text** to your own message
3. Make the words bigger: **Font Size** = 48
4. Run the game again

---

# Checkpoint

Hands up when you can see **your** message in the game window.

---

# Let's Build! (Part 3)

1. Select **Main**, then press **+**
2. Add a **ColorRect**
3. Pick a **Color** you like
4. Drag **ColorRect** **above** **Message** in the list
5. Make it fill the window: **Size** 1152 x 648
6. Save (**Ctrl+S**) and run
