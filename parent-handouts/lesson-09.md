# Parent Handout: Lesson 9, Sound and Music

## What We Did Today
We added sound effects for collecting coins and for getting hit, and background music. We used code to tell the sound nodes when to play.

## Words We Learned
- **AudioStreamPlayer**: a node that plays a sound
- **Stream**: the sound file the player uses
- **Autoplay**: starts by itself when the game starts
- **Loop**: plays again from the start when it ends

## Ask Your Child
"How does the game know when to play a sound? What did the game feel like without sound?"

## Optional Home Activity
Watch a short part of a movie or game with the sound off, and then with the sound on. How does the sound change how you feel?
