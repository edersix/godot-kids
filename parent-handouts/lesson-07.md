# Parent Handout: Lesson 7, Meet the Enemy

## What We Did Today
We added an enemy that walks back and forth. If it touches the hero, the hero goes back to the start. We used **if** to teach the enemy when to turn around.

## Words We Learned
- **Enemy**: a character the hero must avoid
- **Patrol**: walk back and forth along a path
- **if**: do something only when the answer to a question is "yes"
- **Direction**: which way something is going

## Ask Your Child
"What does the enemy ask itself before it turns around?"

## Optional Home Activity
Play "If...": say rules like "If I clap, you jump. If I stomp, you sit." Then try swapping them. Computers follow "if" rules in the same way.
