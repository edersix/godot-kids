# Parent Handout: Lesson 8, Lives and Game Over

## What We Did Today
We gave the hero three lives and a Game Over screen. We learned about **functions**: recipes that we write once and use many times.

## Words We Learned
- **Function**: a recipe, a named group of instructions
- **Call**: use a function, run its recipe
- **Lives**: how many tries the player has left
- **Game over**: when the player has no lives left

## Ask Your Child
"What is a function? Which one did we use many times today?"

## Optional Home Activity
Write a recipe for a simple snack. Then ask: if you needed it five times, would you write the recipe once or five times? That's why computers have functions.
