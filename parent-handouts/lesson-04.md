# Parent Handout: Lesson 4, Walls and Worlds

## What We Did Today
We built four walls around the room so the hero cannot walk away. We learned that things in a game only bump into each other when they have an invisible outline.

## Words We Learned
- **Collision**: two things touching each other
- **Collision shape**: the invisible outline of a thing
- **StaticBody2D**: a node for things that never move, like walls
- **Duplicate**: make an exact copy of a node

## Ask Your Child
"Why did your hero walk through the first wall? How did you fix it?"

## Optional Home Activity
Look around a room. Which things are "solid" (you cannot walk through them) and which are not (like a curtain)? A game has to be told which is which.
