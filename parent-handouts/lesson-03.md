# Parent Handout: Lesson 3, Move the Hero

## What We Did Today
We wrote our first code! We filled in small gaps in a script so the hero walks around with the arrow keys. We also changed the hero's speed to see what happens.

## Words We Learned
- **Script**: a file with instructions for a node
- **Code**: instructions written in words the computer understands
- **Variable**: a named box that remembers something (like the hero's speed)
- **Function**: a group of instructions with a name

## Ask Your Child
"What does the speed variable do? What happens if the speed is a very big number?"

## Optional Home Activity
Play the robot game: one person gives step-by-step instructions ("two steps forward, turn left"), and another follows them exactly. This is how computers follow code.
