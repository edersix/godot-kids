# Parent Handout: Lesson 2, Sprites and Scenes

## What We Did Today
We put our hero on the screen. We learned that a scene is like a tree of nodes, and that a small scene (the hero) can be placed inside a bigger one (the game).

## Words We Learned
- **Sprite**: a picture in a game
- **Parent / child**: a node holding other nodes / a node inside another node
- **Position**: where something is on the screen
- **Instance**: a copy of a scene. The scene is a cookie cutter and each copy is a cookie.

## Ask Your Child
"Which node is the parent and which is the child? Where did you put your hero?"

## Optional Home Activity
Draw a map of a room on paper. Mark the middle with an X. How would you tell a computer where to put a tree? (Hint: how far right, and how far down?)
