# Assessment

Light, kid-friendly assessment for the course. The aim is to celebrate learning, not to grade children.

| File | For | Use |
|------|-----|-----|
| [`certificate.html`](certificate.html) | Children | Print one per child at the end of lesson 12 (A4 landscape) |
| [`skills-checklist.md`](skills-checklist.md) | Children | The child ticks off skills at the end of the course, with help |
| [`observation-sheet.md`](observation-sheet.md) | Facilitators | One per child, filled in during lessons 11 and 12 |

## Printing the Certificate
1. Open `certificate.html` in a browser.
2. Print it on A4 paper, **landscape**, with margins set to **none** and background graphics **on**.
3. Write the child's name, the facilitator's signature, and the date by hand. This also avoids typing children's personal data into files.
4. No logo is included on purpose: this is a volunteer activity. If you ever add a logo, check the owner's branding rules first.

## Tips
- Fill in the observation sheet in lessons 11 and 12, while the children work.
- Give the checklist to the child on the last day, and read the items together.
- Use the observation sheet to give parents a short note, such as one thing that went well and one thing to practice.
